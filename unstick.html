Do not tap a Grove link

A link opens the stuck icon. Type these in Chrome (the colorful circle).

  1. Open Chrome yourself. Do not use the Grove flower icon.
  2. Tap the address bar and type this, then go: chrome://settings/content/all
  3. Search for freshgrove.
  4. Tap app.thefreshgrove.team, then Clear & reset.
  5. Tap the address bar again and type this, then go: app.thefreshgrove.team

If a Fresh Grove app is still in your phone’s Settings → Apps, open it → Storage → Clear storage → Uninstall, then type the address in Chrome again.
