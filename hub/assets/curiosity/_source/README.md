# Drop originals here

Put new curiosity photos in this folder (jpg, png, heic, webp — any name).

Then tell Cursor. It will:

1. Export `full/{id}.webp` and `thumbs/{id}.webp`
2. Register each shot in `js/content.js` with a category, tags, and pairing hint

This folder stays local. Originals are not shipped in the app.
